# Hệ thống quản lý gara và dịch vụ sửa chữa ô tô

## 1. Giới thiệu

Hệ thống quản lý tập trung các nghiệp vụ của gara ô tô: tiếp nhận xe, phân công kỹ thuật viên, lập và xác nhận báo giá, quản lý kho phụ tùng, theo dõi tiến độ sửa chữa, lập hóa đơn, thanh toán và bàn giao xe. Hệ thống giúp thống nhất dữ liệu khách hàng, xe và lịch sử sửa chữa, hỗ trợ tra cứu và hạn chế sai sót trong quá trình vận hành.
